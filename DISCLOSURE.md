# Public disclosure boundary

This case study intentionally includes only high-level engineering information.

Excluded from this repository:

- Application source and compiled binaries
- Organization names, branding, facilities, and personnel
- Hostnames, IP addresses, certificates, credentials, PINs, and connection strings
- Database contents, audit events, logs, screenshots, and support artifacts
- Provisioning, deployment, recovery, and security-bypass scripts
- Proprietary documentation and prior repository history

The diagrams are conceptual and do not reveal production topology. Product names and project-specific implementation details should not be inferred beyond what is stated here.
